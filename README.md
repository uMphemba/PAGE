# Mindful Hero Banner

A stunning, immersive hero banner for a mindfulness web application with video background, smooth animations, and responsive design.

http://umphemba.github.io/PAGE/

---

## Features

- Immersive Video Background - Looping mindfulness video
- Elegant Design - Brand gold (#e2b05c) and teal (#3ba4ab) palette
- Smooth Animations - Staggered fade-in effects
- Fully Responsive - Mobile-first approach
- Typography - Playfair Display + Inter fonts
- Accessible - High contrast WCAG AAA compliant
- Zero Dependencies - Pure HTML, CSS, JavaScript
